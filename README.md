Colour Match  ( Mobile Casual Game )

A fast-paced mobile reflex game developed in Unity for Android. The player must pass a colour-changing ball through the matching colour segment of a rotating multi-coloured ring. Miss the wrong colour and the game ends.

Gameplay Features

Colour-matching mechanic with a rotating segmented ring
Ball colour changes dynamically to challenge the player
Particle explosion effect on incorrect collision
Progressive difficulty scaling to maintain engagement
Real-time score counter
Persistent high score saving using Unity PlayerPrefs
Centralised Sound Manager for audio handling across all game states

Technical Highlights

Built in Unity with C#
Custom particle effects using CFXR particle system
Bloom and glow post-processing using KinoBloom
Advanced visual styling with ToonyColorsPro shaders
Custom HLSL shader code for visual effects
Clean game loop with start screen, gameplay and game over screen
Optimised for portrait mode Android mobile
